🔁 สลับวันหยุด

เลือกวันหยุดที่จะให้มาทำงาน คู่กับวันที่จะหยุดแทน ระบบตั้งให้ทั้งสองวันพร้อมกัน (ลบรายการใดรายการหนึ่ง อีกรายการจะถูกลบด้วย) — ทำใน Telegram ได้เช่นกัน: ปุ่ม ➕ เพิ่มเติม → 🔁 วันหยุด · สลับวัน

📅 วันหยุดบริษัท

วันที่ใส่ไว้ พนักงานจะลาทับไม่ได้ (กันโดนหักเงินฟรี)

🔁 วันทำงานพิเศษ (สลับวันหยุด)

วันอาทิตย์หรือวันหยุดที่ต้องมาทำงาน เพิ่มที่นี่ พนักงานจะลาวันนั้นได้ตามปกติ ส่วนวันที่ไปหยุดชดเชยแทน ให้เพิ่มใน "วันหยุดบริษัท" ด้านบน

💰 รอบเงินเดือน

วันตัดรอบเงินเดือน เช่น 25 = รอบวันที่ 26 เดือนก่อน ถึง 25 เดือนนี้ (ใช้ทั้งยอดลาและยอดโอที)

⏱ โอที
📨 Telegram

แจ้งเตือนเข้ากลุ่มทุกครั้งที่มีคนลาหรือแจ้งโอที เว้นช่อง Token ว่างไว้ = ใช้ค่าเดิม
ครั้งแรก: วาง Token แล้วกดบันทึก (ช่อง Chat ID เว้นว่างได้ ระบบหาให้ตอนกด "เชื่อม Telegram" ในชีต)

🔑 เปลี่ยนรหัส PIN ผู้ดูแล
⚠️ ตอนนี้ยังใช้ PIN เริ่มต้น 1234 ซึ่งเดาได้ง่าย ควรเปลี่ยนเป็นรหัสของคุณเอง
ℹ️ ทำในไฟล์ Google Sheet

• คู่มือและคำอธิบายทุกชีต: ชีตแรกชื่อ อ่านก่อน
• ค่าแรงรายวันและโควต้าลา: กรอกในชีต รายวัน_TH / รายวัน_MM
• ยอดลา + ยอดโอที ตามรอบเงินเดือน: ชีต Payroll_TH / Payroll_MM
• รายการโอทีทั้งหมด: ชีต OT
• ส่งออกไฟล์สรุปให้ฝ่ายบัญชี และเชื่อม Telegram: เมนู ระบบลา ด้านบนของชีต
